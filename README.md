# ✦ ABOUT LICODE

**LICODE** is a front-end development and creative web space focused on building modern digital experiences.

We explore the intersection of

### `DESIGN` × `CODE` × `INTERACTION` × `MOTION`

From focused UI components to complete web experiences, LICODE creates interfaces that are:

`VISUAL` · `RESPONSIVE` · `INTERACTIVE` · `ACCESSIBLE` · `MAINTAINABLE`

> **We don't just build interfaces.**  
> **We build experiences worth exploring.**
