# ✦ ABOUT LICODE

<br>

</div>

<div align="center">

**LICODE** is a front-end development and creative web space
focused on building modern digital experiences.

<br>

We explore the intersection of

### `DESIGN` × `CODE` × `INTERACTION` × `MOTION`

<br>

From focused UI components to complete web experiences,
LICODE creates interfaces that are:

<br>

`VISUAL` · `RESPONSIVE` · `INTERACTIVE` · `ACCESSIBLE` · `MAINTAINABLE`

<br>
<br>

> **We don't just build interfaces.**
>
> **We build experiences worth exploring.**

</div>
